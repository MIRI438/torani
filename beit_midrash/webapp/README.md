# אתר שאלות-ותשובות - עדים זוממים

אתר קטן: שדה שאלה, ותשובה שנוצרת ע"י Claude אך ורק על סמך המקורות ב-
`api/corpus.json` (אותו תוכן שיש היום במסד הנתונים) - הכללים האלה קבועים
ב-prompt של `api/ask.js` ולא ניתנים לעקיפה מהדפדפן.

## איך זה עובד

- `index.html` - ממשק הצ'אט (סטטי, בלי בנייה).
- `api/ask.js` - פונקציית שרת (Vercel Serverless Function) שמקבלת שאלה,
  בונה prompt עם כל המקורות, וקוראת ל-API של Anthropic. מפתח ה-API נשמר
  כמשתנה סביבה בצד השרת בלבד - לעולם לא נחשף לדפדפן.
- `api/corpus.json` - תמונת מצב של תוכן מסד הנתונים. כדי לעדכן אותו אחרי
  שמוסיפים תוכן חדש: להריץ מחדש את הסקריפט שיצר אותו (ראה
  `../scripts/`), ואז לדחוף (push) את הקובץ המעודכן.

## הקמה (חד-פעמית, כ-5 דקות)

1. **הרשמה ל-Vercel** (חינם): כניסה ל- https://vercel.com/signup, הכי
   פשוט להתחבר עם חשבון ה-GitHub שלך.
2. **יבוא הפרויקט**: ב-Vercel, "Add New" → "Project" → לבחור את הריפו
   `MIRI438/torani` (או השם הנוכחי של הריפו).
3. **חשוב**: בשלב ההגדרות (Configure Project), תחת "Root Directory" -
   ללחוץ Edit ולבחור `beit_midrash/webapp`. (ה-framework preset יכול
   להישאר "Other".)
4. **מפתח API**: לפני שלוחצים Deploy, תחת "Environment Variables" -
   להוסיף משתנה בשם `ANTHROPIC_API_KEY` עם הערך שמקבלים מ-
   https://console.anthropic.com/settings/keys (צריך חשבון Anthropic;
   התשלום הוא לפי שימוש בפועל - לכמות שאלות אישית זה עולה סנטים בודדים
   לחודש, לא מנוי).
5. **Deploy**. אחרי כדקה יופיע קישור קבוע לאתר (כתובת מהצורה
   `https://your-project.vercel.app`) - זה הקישור לשימוש קבוע.

מרגע זה, כל דחיפה (push) ל-branch הראשי של הריפו מעדכנת את האתר אוטומטית
- אין צורך לחזור על שלבי ההקמה.
