# בית מדרש - מאגר מקורות תורניים

מסד נתונים למערכת "בית מדרש" תורנית: מקורות טקסטואליים (פסוקים, משניות,
תוספתא, גמרא, פרשנים...) מתויגים במספר ממדים במקביל - שכבה היסטורית, פנים
(פרד"ס), סוגה, וקשרים בין מקורות - כדי לאפשר בניית "סוגיות" שלמות דרך
שאילתות, בלי לשכפל טקסט ובלי עץ תיקיות נוקשה.

הפרויקט ממשיך התכתבות קודמת (מסמכי docx שהועברו לכאן) שבה כבר סוכמו מבנה
הנתונים והחלטות התיוג הראשוניות. סיכום ההחלטות שכבר התקבלו מופיע למטה.

## מבנה הנתונים

`db/schema.sql` - הטבלה המרכזית `sources` (מקור בודד: תוכן, שפה, שכבה,
מראה מקום), מתויגת דרך:

- `layers` - שכבה היסטורית אחת לכל מקור (1-לרבים), עם `order_rank` שקובע
  את סדר הלימוד: תנ"ך → תרגומים → משנה → תוספתא → תלמוד → גאונים →
  ראשונים → אחרונים → פוסקים (9 שכבות).
- `faces` (פשט/רמז/דרוש/סוד) ו-`genres` (הלכה/אגדה/מחשבה/קבלה) - רבים-לרבים,
  כי מקור יחיד יכול להיקרא בכמה פנים ולהיות משוייך לכמה סוגות בו-זמנית.
- `sugyot` - קיבוץ נושאי (כגון "עדים זוממים"), רבים-לרבים.
- `connections` - קשר מכוון בין שני מקורות עם `relation_type` (למשל
  "מפרש"), טבלת יחסים פתוחה ומתרחבת לפי הצורך.

`scripts/beit_midrash_lib.py` - שכבת גישה לנתונים: `add_source`,
`add_connection`, ואכיפת היררכיה (`enforce_hierarchy`, ברירת מחדל True) -
אי אפשר להזין מקור לשכבה מסוימת כל עוד שכבה מוקדמת ממנה עדיין ריקה.

## מצב נוכחי

הרצת `python3 scripts/seed_edim_zomemim.py` בונה מחדש את
`db/beit_midrash.sqlite` ומזינה את סוגיית **עדים זוממים** (דברים יט,
טו-כא):

| שכבה     | כמות | מקור                                                    |
|----------|------|----------------------------------------------------------|
| תנ"ך     | 7    | הוזן ע"י המשתמש (עם ניקוד וטעמים)                        |
| תרגומים  | 14   | תרגום אונקלוס + תרגום יונתן, מאוצריא                     |
| משנה     | 10   | מכות פרק א, הוזן ע"י המשתמש (זהה למקור באוצריא)          |
| תוספתא   | 6    | מכות פרק א, מאוצריא                                      |

כל השכבות שהוזנו עברו את אכיפת ההיררכיה בלי צורך לנטרל אותה - כולל שכבת
התוספתא, שבניסיון הקודם נשארה ריקה וחסמה את הזנת התלמוד.

## אוצריא כמקור טקסטים

`scripts/otzaria_fetch.py` שולף ספרים בודדים ממאגר הטקסטים הפתוח
[Otzaria](https://github.com/Sivan22/otzaria) (מבוסס על טקסטים של Sefaria
ו-Dicta) **בלי להוריד את הארכיון המלא** (כ-1.3GB): הוא שולף רק את רשימת
הקבצים (Central Directory של קובץ ה-zip) ואז שולף ומפענח רק את הקובץ
המבוקש, דרך HTTP Range requests.

```
python3 scripts/otzaria_fetch.py list "מכות"          # חיפוש שמות ספרים
python3 scripts/otzaria_fetch.py get "<שם מדויק>" out.txt
```

טקסטים גולמיים שנשלפו נמצאים תחת `sources/raw/` (מסומנים `_otzaria` בשם
הקובץ).

## החלטות שכבר התקבלו (מההתכתבות הקודמת)

- גרעיניות: כל פסוק/משנה/הלכה = שורה נפרדת בטבלת `sources`.
- סדר עבודה: קודם שכבה היסטורית שלמה, פנים פשט לפני דרש לפני סוד (רמז
  נדחה לעתיד).
- שדה `reference` הוא לזיהוי בלבד (כגון "דברים יט, טו") ולא לפרשנות.
- אין להוסיף תוכן או פרשנות שלא הוזנו במפורש ע"י המשתמש.

## שאלות פתוחות / הצעד הבא

1. **שם הוי"ה בפסוקים** - הטקסט שהמשתמש הזין מנקד "לִפְנֵי יְקֹוָק" (ניקוד
   מקובל להימנע מהגיה), ואילו טקסט אוצריא/ספריא מנקד "לִפְנֵי יְהֹוָה".
   שתי הצורות מקובלות בדפוסים שונים - נשמר כרגע נוסח המשתמש כפי שהוזן
   במפורש, לא הוחלף.
2. **גבול פרק א בגמרא ורש"י** - טקסט אוצריא מכיל 12 סימוני "מַתְנִי'" בין
   דף ב. לדף ז:, בעוד שבפרק א יש רק 10 משניות. כלומר משניות פרק ב מתחילות
   כבר בתוך דף ז:, והגבול המדויק טרם אותר. הטקסטים הגולמיים (מכות דף
   ב.-ח., גם מהמשתמש וגם מאוצריא) נשמרו ב-`sources/raw/` אך **טרם הוזנו**
   ל-DB כשורות אטומיות - כדי לא לשבש את הסוגיה בטעות.
3. **פרשנים על הפסוקים** - ברשימת המחברים שכבר תוכננה (תרגום אונקלוס/יונתן
   ✓, ילקוט שמעוני, מדרש אגדה, רש"י, רמב"ן, אבן עזרא, הדר זקנים, חזקוני,
   רבנו בחיי, ריב"א, רלב"ג, רשב"ם, תפסיר רס"ג, מלבי"ם) - כולם אותרו
   באוצריא ומוכנים לשליפה, טרם הוזנו.
